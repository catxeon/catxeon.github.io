# Коллекция банковских карт

Статический сайт-каталог коллекции с классификацией и сканами обеих сторон.
Хостится на GitHub Pages, собирается локально одним скриптом.

## Как устроено

В репозитории лежит только то, что нужно самому сайту. Инструментарий
(`tools/*.py`, `editor.html`, стили и скрипт редактора, `requirements.txt`)
и оригиналы сканов остаются локально — они перечислены в `.gitignore`.

```
scans/            оригиналы 600 dpi — только локально
tools/            скрипты сборки и редактор — только локально
data/cards.json   база: пары сканов, классификация, маски. Источник правды
data/site.json    выжимка для сайта, генерируется сборкой
img/              публикуемые картинки: маски выжжены в пиксели
index.html        лендинг — точка входа, кнопка ведёт в галерею
collection/       галерея; лежит папкой, чтобы адрес был /collection/ без .html
editor.html       локальный редактор (работает только через tools/serve.py)
```

Из-за этого на другой машине репозиторий сам по себе коллекцию не пересоберёт:
чтобы добавлять карты, нужны `tools/` и `scans/` с этого компьютера.
`data/cards.json` в git оставлен намеренно — это единственная копия всей
разметки, и других резервных копий у неё нет.

Оригиналы 600 dpi в git не уезжают никогда — публикуется только то, что
собрал `build.py`. Для каждой стороны решение принимается явно: либо на ней
расставлены маски, либо стоит отметка «маскировать нечего». Без одного из
двух карта не публикуется.

## Установка

```
python -m pip install -r requirements.txt
```

Если скрипт ругается «Не хватает библиотек», значит пакеты стоят в другом
интерпретаторе. Сообщение печатает полный путь к тому python, которым скрипт
запущен, — ставить надо именно в него:

```
"C:\Python314\python.exe" -m pip install -r requirements.txt
```

## Работа с коллекцией

Импорт новых сканов (кладём png в `scans/`, потом):

```
python tools/ingest.py --dry-run    # посмотреть, как разложатся пары
python tools/ingest.py              # записать в data/cards.json
```

Классификация и маски:

```
python tools/serve.py               # редактор: http://127.0.0.1:8777/editor
```

В редакторе: `←` `→` — переключение карт, `D` — отметить готовой, `R` —
повернуть сторону, `Ctrl+S` — сохранить. Маска рисуется протягиванием мыши
по картинке, клик по маске удаляет её. Сохранение автоматическое.

Сборка публичной части:

```
python tools/build.py
```

Флаги: `--format png` (вместо webp), `--max-width 0` (исходное разрешение),
`--all` (публиковать и незавершённые карты), `--force` (перерисовать всё).

## Страницы

* `index.html` — лендинг. Число карт и веер сканов на нём подтягиваются
  из `data/site.json`, так что после `build.py` он обновляется сам.
  Адрес почты собирается в рантайме в `assets/landing.js` — в исходном HTML
  его нет, чтобы не выгребли спам-боты.
* `collection/index.html` — галерея, открывается как `/collection/`.

Расширений `.html` в адресах нет: на статике это делается папками, поэтому
галерея лежит в `collection/`, а не файлом `collection.html`. Запрос
`/collection` хостинг сам redirect'ит на `/collection/`.

Из-за этого пути к ассетам, данным и картинкам — **от корня** (`/assets/…`,
`/data/site.json`, `/img/…`), иначе из подпапки они разрешались бы в
`/collection/assets/…`. Значит, сайт должен раздаваться с корня домена
(`petya.cc`), а не из подкаталога. Пути картинок проставляет `build.py`.

Локальный сервер повторяет ту же раскладку: `/` — лендинг, `/collection/` —
галерея, `/editor` — редактор.

## Что публикуется

Карта попадает на сайт, только если:

1. у неё статус «готово», и
2. у каждой отсканированной стороны есть либо маски, либо отметка
   «маскировать нечего».

Иначе `build.py` её пропускает и печатает предупреждение. Это защита от
случайной публикации действующих реквизитов.

## Публикация на GitHub Pages

```
git init
git add -A
git commit -m "Каталог коллекции карт"
git branch -M main
git remote add origin git@github.com:USER/REPO.git
git push -u origin main
```

Дальше в настройках репозитория: Settings → Pages → Source: `Deploy from a
branch`, ветка `main`, папка `/ (root)`.

## Проверка перед пушем

```
python tools/build.py
git status --short
```

Убедиться, что в списке нет файлов из `scans/`.
